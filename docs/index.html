Save any web page as clean Markdown

A Chrome extension that turns the page you are reading — or just the part you highlighted — into a Markdown file with YAML frontmatter, ready for Obsidian.

View on GitHub Install

What it does

Readable output

Navigation, ads, and sidebars stripped by Mozilla Readability. You keep the article, not the furniture.

Frontmatter for your vault

Title, source URL, author, publication date, capture time, tags — pick exactly which fields appear.

Markdown that survives

GFM tables, code blocks that keep their language, nested lists at the right indent, absolute URLs.

An editor, not a popup

Formatting toolbar and live preview, so you fix things before the file lands on disk.

Only when you ask

It asks for activeTab alone, so it can read nothing until you click, and costs nothing on pages you never save.

Nothing leaves your machine

No server, no account, no analytics, no tracking. Privacy policy.

How to use it

  1. Open the page you want to keep.
  2. Click the toolbar icon, press Ctrl+Shift+M (⌘+⇧+M on Mac), or right-click and choose Save Page To Markdown. Highlight a passage first and only that part is captured.
  3. The editor opens in a new tab. Fix the title, trim anything you don't want.
  4. Hit Save Page To Markdown — or Copy, if it is going straight into a note.

Make it yours

Filename templates with {title} {slug} {domain} {date} — a / creates a subfolder. Choose how images are handled, which frontmatter fields appear, heading style, bullet marker, and fenced or indented code blocks.
